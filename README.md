Entry for the [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty on [make.fun](https://make.fun).

`main.ts` writes a single sentence of at most 200 characters explaining the
modern internet to a time traveler arriving from the year 1800, to
`/output/entry.txt`. The sentence is built only from things a person from
1800 already knows — a library, a post office, a market stall, a road — and
is the same on every run.

## Run

```sh
node main.ts   # Node 22.18+
```
